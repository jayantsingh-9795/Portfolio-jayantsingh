## 📖 About the Project

This portfolio is designed to present **Jayant Singh's** professional identity online. It combines a clean layout with subtle gradient accents to create a trustworthy, career-focused impression.  
The site includes:

- A hero section with profile picture upload
- Dual **Career Objective** statements
- Address and contact information
- Skills grid (text-only, no icons per request)
- Certifications, hobbies (bullet list), resume snapshot
- Functional contact form and working social media links

---

## ✨ Features

- ✅ **Fully Responsive** – Works on desktop, tablet, and mobile devices
- ✅ **Profile Image Upload** – Visitors can upload a custom profile photo (client-side)
- ✅ **One-Click Resume Download** – Generates and downloads a `.pdf` resume file
- ✅ **Career Objective Section** – Two professional statements presented side by side
- ✅ **Social Media Integration** – Working Facebook, Instagram, LinkedIn links
- ✅ **Contact Form** – Frontend validation with success/error feedback
- ✅ **Smooth Scrolling Navigation** – Internal anchor links with smooth scroll behavior
- ✅ **Modern Gradient Color Scheme** – Professional HD gradients (Deep Navy, Steel Blue, Warm Gold)
- ✅ **No Icons in Skills/Address Sections** – Clean text-only presentation as requested
